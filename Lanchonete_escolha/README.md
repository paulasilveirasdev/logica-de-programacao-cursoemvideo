# Simulador de Lanchonete (Estrutura Escolha-Caso)

Projeto desenvolvido em **Visualg** como parte dos exercícios do Curso em Vídeo (Gustavo Guanabara). 

## 🎯 Objetivo
Praticar o uso da estrutura condicional de múltipla escolha (`Escolha-Caso`) combinada com cálculos matemáticos básicos e validação de entrada de dados.

## 🛠️ Tecnologias
- **Visualg** (Sintaxe de Algoritmos)
