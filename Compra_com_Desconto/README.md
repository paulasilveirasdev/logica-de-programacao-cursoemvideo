# Compra com Desconto

## Sobre o projeto
Exercício desenvolvido durante os estudos de Lógica de Programação e Algoritmos, utilizando VisualG.

O programa simula uma compra com desconto de acordo com a categoria do cliente.

## Conceitos praticados
- Funções com parâmetros e retorno.
- Estrutura condicional `Se...Então`.
- Estrutura de repetição `Repita...Até`.
- Cálculos matemáticos.
- Validação de dados.

## Regras de desconto
- Bronze: 10%
- Prata: 15%
- Ouro: 20%

## Objetivo
Praticar funções, condições e repetições na construção de um programa simples.
