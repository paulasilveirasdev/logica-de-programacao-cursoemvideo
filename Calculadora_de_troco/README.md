# 🧮 Calculadora de Troco

## 📌 Sobre o projeto

Este projeto foi desenvolvido utilizando **VisuAlg**, como parte dos meus estudos em Lógica de Programação e Algoritmos.

O objetivo é praticar os conceitos fundamentais da programação por meio de um algoritmo que simula o cálculo de troco em uma compra.

## 🎯 Funcionalidades

O algoritmo permite:

- Informar o preço do produto.
- Informar o valor pago pelo cliente.
- Calcular o troco.
- Identificar quando o pagamento é exato.
- Verificar quando o valor pago é insuficiente.

## 🧠 Conceitos praticados

- Declaração de variáveis.
- Tipos de dados (`real`).
- Entrada e saída de dados (`Leia` e `Escreva`).
- Operadores aritméticos.
- Estruturas condicionais (`Se`, `Senao`).
- Condicionais aninhadas.

## 🛠️ Tecnologia utilizada

- VisuAlg

## 🧪 Exemplos de execução

| Preço do produto | Valor pago | Resultado          |
| ---------------- | ---------- | ------------------ |
| R$ 25,00         | R$ 100,00  | Troco de R$ 75,00  |
| R$ 25,00         | R$ 25,00   | Pagamento exato    |
| R$ 25,00         | R$ 20,00   | Valor insuficiente |

## 📚 Objetivo de aprendizagem

Desenvolver o raciocínio lógico, compreender a estrutura de um algoritmo e praticar a resolução de problemas por meio da programação.
