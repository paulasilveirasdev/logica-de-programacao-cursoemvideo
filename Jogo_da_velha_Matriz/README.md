# Jogo da Velha — Inicialização de Matriz

## Sobre o projeto
Exercício desenvolvido durante meus estudos de Lógica de Programação e Algoritmos, utilizando o Portugol Studio/VisualG.

O objetivo foi praticar a criação e o preenchimento de uma matriz 3x3, simulando a estrutura inicial de um tabuleiro de jogo da velha.

## Conceitos praticados
- Matrizes (linhas e colunas).
- Variáveis.
- Laços de repetição (`Para`).
- Contador.
- Conversão de números em caracteres.

## Funcionamento
O programa percorre as três linhas e as três colunas da matriz, preenchendo cada posição com números de 1 a 9.

## Objetivo do aprendizado
Compreender como declarar, acessar e preencher posições de uma matriz utilizando estruturas de repetição.
