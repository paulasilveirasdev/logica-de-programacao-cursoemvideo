# 📚 Calculadora de Notas

## Sobre o projeto

Algoritmo desenvolvido em VisuAlg para calcular a média de um aluno e identificar sua situação acadêmica.

## Funcionalidades

- Receber o nome do aluno.
- Receber duas notas.
- Calcular a média.
- Informar se o aluno foi aprovado, está em recuperação ou reprovado.

## Conceitos praticados

- Variáveis e tipos de dados.
- Entrada e saída de dados.
- Operadores aritméticos e relacionais.
- Estruturas condicionais (`Se` e `Senao`).
- Condicionais aninhadas.

## Tecnologia

- VisuAlg
