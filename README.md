Este repositório reúne pequenos projetos desenvolvidos durante meus estudos de Lógica de Programação e Algoritmos, utilizando VisuAlg.

O objetivo é praticar os fundamentos da programação, desenvolver o raciocínio lógico e construir uma base sólida para o aprendizado de linguagens de programação.

🎯 Objetivos de aprendizagem

1-Compreender a lógica por trás dos algoritmos.

2-Praticar a declaração e utilização de variáveis.

3-Trabalhar com entrada e saída de dados.

4-Utilizar operadores aritméticos e relacionais.

5-Desenvolver soluções com estruturas condicionais.

6-Praticar estruturas de repetição.
