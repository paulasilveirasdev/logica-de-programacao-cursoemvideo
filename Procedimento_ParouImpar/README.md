# Analisador de Par ou Ímpar com Procedimentos

Projeto desenvolvido em **Visualg** como parte dos exercícios do Curso em Vídeo (Gustavo Guanabara).

## 🎯 Objetivo
Praticar a criação e chamada de **Procedimentos** com passagem de parâmetros para modularizar o código e reaproveitar a lógica de validação.

## 🛠️ Tecnologias
- **Visualg** (Sintaxe de Algoritmos)
