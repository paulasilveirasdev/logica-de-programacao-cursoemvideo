# Tabuada Personalizada (Estrutura Enquanto)

Projeto desenvolvido em **Visualg** como parte dos exercícios do Curso em Vídeo (Gustavo Guanabara).

## 🎯 Objetivo
Praticar o uso de laços de repetição (`Enquanto-Faca`) e variáveis acumuladoras/contadoras para automatizar cálculos matemáticos sequenciais.

## 🛠️ Tecnologias
- **Visualg** (Sintaxe de Algoritmos)
